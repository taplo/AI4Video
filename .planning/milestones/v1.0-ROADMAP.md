## Overview

AI4Video 工程化升级的第一阶段完成。从 rebucca 重命名到安全加固、测试体系建设、依赖升级，完成了项目从原型到生产就绪的全面改造。

### Phase 02: onnx-fix

**Goal:** 修复 ONNX 模型上传后检测报错问题
**Depends on:** —
**Plans:** 2 plans

Plans:
- [x] 02-01: 自动检测 algorithm_type，输入自动 resize，shape mismatch 日志

**Details:**

### Phase 03: architecture-upgrade

**Goal:** 架构升级，消除全局锁，迁移到 Django ORM
**Depends on:** Phase 04
**Plans:** 4 plans

Plans:
- [x] 03-01: SQLite WAL 模式，.env 敏感配置，Config 线程安全
- [x] 03-02: Django ORM 迁移，BaseModel mixin
- [x] 03-03: AnalysisManager 进程池改造
- [x] 03-04: 优雅关闭信号处理

**Details:**
将全局 `g_dbLock` 替换为 Django ORM connection pooling，将所有 raw SQL 查询迁移到 Django ORM，实现 `BaseModel` mixin 消除重复的 `save()`/`delete()` 方法，将 config.json 敏感值迁移到环境变量，实现配置热重载的线程安全机制，将 AnalysisManager 的 multiprocessing 改为基于 `concurrent.futures` 的进程池，实现优雅关闭信号处理。
