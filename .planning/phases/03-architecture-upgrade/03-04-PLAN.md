**Line 34 — SELECT with pull_stream_type filter:**
Replace `g_database.select("select id,pull_stream_username,pull_stream_password from av_stream where pull_stream_type=1 order by id desc limit 1")` with:

**Line 212 — SQL INJECTION (select * where code='%s'):**
Replace `g_database.select("select * from av_stream where code='%s' limit 1" % stream_code)` with:
```python
stream_obj = StreamModel.objects.filter(code=stream_code).first()
if stream_obj:
    stream_info = {field.name: getattr(stream_obj, field.name) for field in StreamModel._meta.get_fields() if hasattr(stream_obj, field.name)}
    # Handle ForeignKey fields

    if camera_device_id is None or camera_device_id == "":
```

Note: The existing code returns a flat dict from raw SQL. The ORM approach returns model instances. Convert to dict using `_meta.get_fields()` or manually construct the dict with the same keys the template expects. The safer approach is to manually construct the dict with the exact fields the template uses:
```python
stream_info = {
    "id": stream_obj.id,
    "code": stream_obj.code,
    "app": stream_obj.app,
    "name": stream_obj.name,
    # ... all fields the template expects
}
```
