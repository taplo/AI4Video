self._setup_signal_handlers()

**Step 2: Implement _setup_signal_handlers** (per D-15)
Create method that registers SIGTERM and SIGINT handlers. Use `threading.Event` for coordination (Pitfall 4 from RESEARCH.md — do NOT do cleanup directly in signal handler, just set the event):
```python
def _setup_signal_handlers(self):
    def handler(signum, frame):
        logger.info("收到信号 %d，开始优雅关闭...", signum)
        self.shutdown(timeout=30)
    signal.signal(signal.SIGINT, handler)
    signal.signal(signal.SIGTERM, handler)
```
Import `signal` and `sys` at the top of the file.

**Step 3: Implement shutdown method** (per D-15)
Add `shutdown(self, timeout=30)` method that:
1. Sets `self._shutdown_event`
2. Calls `self._executor.shutdown(wait=False, cancel_futures=True)` to stop accepting new tasks
3. Collects all running Futures from `self._pipelines`
4. Waits for them with timeout using `concurrent.futures.as_completed(futures, timeout=timeout)`
5. Logs any exceptions during shutdown

**Step 4: Add heartbeat health check** (per D-16)
Add `_health_check_loop` method running in a daemon thread that:
1. Periodically (every 30 seconds) iterates over `self._pipelines`
2. For each pipeline, checks if the Future is done (completed/cancelled/exception)
3. If a pipeline's Future is done with an exception, logs the error and optionally restarts
4. Updates pipeline status info with health indicators

Start the health check thread in `__init__`:
```python
self._health_thread = threading.Thread(target=self._health_check_loop, name="health-check", daemon=True)
self._health_thread.start()
```

**Step 5: Update start() to reject new tasks during shutdown** (per D-15)
At the beginning of `start()`, add check:
```python
if self._shutdown_event.is_set():
    return False, "shutting down"
```

**Step 6: Add import for signal and sys** (per D-15)
Add at the top of the file: `import signal` and `import sys`.
