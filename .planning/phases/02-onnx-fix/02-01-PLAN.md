<objective>
Fix ONNX model detection by adding algorithm_type auto-detection at probe time, auto-resizing input to match model shape, and adding comprehensive error logging throughout the detection pipeline.

Purpose: Users upload YOLO models (v5/v8/v11/v26) but the system defaults to "yolo8", causing postprocessing to misinterpret output tensors and produce garbage results. This plan makes the system auto-detect the correct version and adapt to the model's actual input dimensions.

Output: Modified SmallModelView.py (probe response with new fields), onnx_engine.py (auto-resize + error logging), yolo_postprocess.py (mismatch logging).
</objective>
