def f_parseRequestIp(request):
    x_forwarded_for = request.META.get('HTTP_X_FORWARDED_FOR')
    if x_forwarded_for:
        ip = x_forwarded_for.split(',')[0].strip()
    else:
        ip = request.META.get('REMOTE_ADDR', '0.0.0.0')
    return ip

def f_error_response(code, msg, detail=None, status_code=400):
    return JsonResponse({
        "code": code, "msg": msg, "detail": detail,
        "timestamp": int(time.time()),
    }, status=status_code)

**Part A — RateLimitMiddleware (app/middleware.py):**

Add a new `RateLimitMiddleware` class after the existing `SimpleMiddleware`. This middleware uses django-ratelimit's core rate checking (import `from django_ratelimit.core import is_rate_limited`) to check rate per-IP per request, per D-05 (IP dimension), D-06 (200/min threshold), D-07 (all endpoints except /inner/), D-08 (429 + JSON), D-09 (django-ratelimit), D-10 (same rate for logged-in and anonymous).

The middleware should:
1. In `__init__`, store `self.get_response`
2. In `__call__`:
   - Get the request path
   - Skip rate check if path starts with `/inner/` or `/static/` or `/api/health`
   - Get the client IP using the same logic as `f_parseRequestIp` (from ViewsBase)
   - Use `is_rate_limited(request, group=None, key='ip', rate='200/m', method=ratelimit.ALL)` to check
   - If rate limited, return `JsonResponse({'code': 4290001, 'msg': '请求过于频繁，请稍后再试', 'detail': None, 'timestamp': int(time.time())}, status=429)`
   - Otherwise call `self.get_response(request)`
3. Import ratelimit methods: `from django_ratelimit.core import is_rate_limited` and `from django_ratelimit import ALL`

**Part B — AuditMiddleware (app/middleware.py):**

Add `AuditMiddleware` class after RateLimitMiddleware. This logs authentication events and data modifications per D-11.

The middleware should:
1. In `__call__`:
   - Store the request path and method before calling `self.get_response(request)`
   - After getting the response, check if the path starts with `/api/` (skip `/api/health`)
   - Determine the action type:
     - POST to `/login` → check response status: if redirect to `/` → 'login', otherwise → 'login_failed'
     - POST to `/logout` → 'logout'
     - POST to any other path → map HTTP method: POST→'create', PUT/PATCH→'update', DELETE→'delete'
     - GET/HEAD → skip (no audit needed for reads)
   - For non-read actions, create an AuditLog entry:
     - `user_id`: from `request.session.get('user', {}).get('id')` or None
     - `username`: from `request.session.get('user', {}).get('username', '')` or ''
     - `ip_address`: use `f_parseRequestIp(request)` from ViewsBase
     - `action`: determined above
     - `resource`: the request path
     - `details`: `{'method': request.method, 'status_code': response.status_code}`
     - `success`: `200 <= response.status_code < 400`
   - Always return the original response
