# Plan 05-01: Test Framework Setup

## Objective
Establish pytest framework with configuration, shared fixtures, and test dependencies.

## Tasks

### Task 1: Create pytest.ini
<read_first>
- .planning/phases/05-test-infrastructure/05-RESEARCH.md (pytest configuration patterns)
- .planning/codebase/CONVENTIONS.md (code style)
</read_first>

<action>
Create `pytest.ini` in project root with:
- `DJANGO_SETTINGS_MODULE = framework.settings`
- `python_files = tests.py test_*.py`
- `python_classes = Test*`
- `python_functions = test_*`
- `addopts = -v --tb=short --strict-markers --cov=app --cov-report=term-missing --cov-report=html --cov-fail-under=60`
- Markers: `slow`, `integration`
</action>

<acceptance_criteria>
- File `pytest.ini` exists at project root
- Contains `DJANGO_SETTINGS_MODULE = framework.settings`
- Contains `--cov-fail-under=60`
- Running `pytest --co` (collect-only) does not error
</acceptance_criteria>

### Task 4: Create tests/conftest.py
<read_first>
- .planning/phases/05-test-infrastructure/05-RESEARCH.md (conftest.py patterns)
- app/utils/GlobalUtils.py (g_config, g_zlm, g_logger globals)
- app/utils/Config.py (Config class interface)
</read_first>

<action>
Create `tests/conftest.py` with:
- `@pytest.fixture(autouse=True)` for Django settings (DJANGO_SECRET_KEY='test-secret', DEBUG='true')
- `config_data` fixture returning minimal valid config dict
- `config_file` fixture writing tmp config.json via `tmp_path`
- `mock_g_config` fixture replacing `app.utils.GlobalUtils.g_config` via `monkeypatch`
- `mock_g_zlm` fixture replacing `app.utils.GlobalUtils.g_zlm` with mock
- `mock_g_logger` fixture replacing `app.utils.GlobalUtils.g_logger` with mock
</action>

<acceptance_criteria>
- File `tests/conftest.py` exists
- Contains `@pytest.fixture(autouse=True)` function named `_set_django_settings`
- Contains fixtures: `config_data`, `config_file`, `mock_g_config`, `mock_g_zlm`, `mock_g_logger`
- Running `pytest --co` collects fixtures from conftest.py
</acceptance_criteria>

## Verification
- Run `pytest --co` to verify configuration loads
