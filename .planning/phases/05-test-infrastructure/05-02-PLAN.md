# Plan 05-02: Unit Tests (No DB)

## Objective
Create unit tests for pure utility functions that don't require database access.

## Tasks

### Task 1: Create tests/test_config.py
<read_first>
- app/utils/Config.py (source of truth for _bool, _int, _float, _resolve_path, Config class)
- .planning/phases/05-test-infrastructure/05-RESEARCH.md (test patterns for Config)
</read_first>

<action>
Create `tests/test_config.py` with classes:
- `TestBoolHelper`: test `_bool()` with None, bool, int, string inputs ("true","1","yes","on","false","0","no","off"), whitespace
- `TestIntHelper`: test `_int()` with valid int, string int, None, invalid string, float truncation
- `TestFloatHelper`: test `_float()` with valid float, int, None, invalid
- `TestResolvePath`: test `_resolve_path()` with absolute path, relative path, empty string, None
- `TestConfigInit`: test Config class with valid config file, missing file, GBK encoding fallback
- `TestConfigToDict`: test `to_dict()` returns complete snapshot
- `TestConfigSaveFromWeb`: test `saveFromWeb()` merges string/int/bool params correctly
</action>

<acceptance_criteria>
- File `tests/test_config.py` exists
- Contains at least 20 test functions
- Running `pytest tests/test_config.py -v` passes all tests
- Coverage for `app/utils/Config.py` is at least 80%
</acceptance_criteria>
